# Academic / Literature Review Report Template (route-specific)

**When to read:** only when the **academic-review** route is selected and the
field-progress sub-style is used (see the route's card in
`references/routes/academic-review.md`). The core default structure lives in
`references/report-template.md`; this file adds the optional recommendations
block that follows the bottom line.

### 7b. Academic-review recommendations (optional, academic-review route only)

当报告使用 **Academic / Literature Review** 路由且启用了 **field-progress analysis** 子风格时，建议在 bottom line 之后包含一个 recommendations 区块。该区块不替代 bottom line，而是为读者提供可操作的下步指引。

```
## 研究者 / 实践者下一步

**研究者方向：**
- [具体建议 1，如 "下一步应设计 XXX 评测方法以分离 YYY 和 ZZZ 两种能力"]
- [具体建议 2]
- ...

**实践者方向：**
- [具体建议 1，如 "部署前应在 no-image 基线条件下验证，排除语言捷径" ]
- [具体建议 2]
- ...

**监控指标：**
- [读者应关注哪些指标或论文类型]
```

**纪律要求**：
- 所有建议必须标注为 **recommendation**（推荐/建议），不可写成已确认的预测或事实
- 建议应来源于报告中已分析的证据（引用的论文、benchmark、争议），而非凭空提出
- 可附带优先级暗示（通过列表顺序或显式标记），但无需定量优先级评估
- 不降低报告的证据纪律要求（Source Register、claim-level citation 等仍需满足）
